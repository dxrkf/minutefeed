# العربية

عندك مصادر كثيرة ووقت قليل للقراءة؟

بنيت MinuteFeed: أداة تجمع RSS وAtom في موجز ضمن ميزانية وقت تختارها. تتناوب بين المصادر، تزيل تكرار الروابط، وتنتج HTML أو JSON بدون مفتاح API أو مكتبات Python خارجية.

اجتازت 23 اختبارًا، ونجحت تجربة حية على مصدرَي NASA وPython Insider: أربع مواد بوقت قراءة تقديري قدره 40 ثانية ضمن ميزانية دقيقة.

المقتطفات من الناشرين، وليست ملخصات ذكاء اصطناعي. تقدير الوقت يخص العناوين والمقتطفات المعروضة، ولا يشمل المقالات الكاملة.

https://github.com/dxrkf/minutefeed

# English

Too many feeds, too little reading time?

MinuteFeed turns live RSS and Atom feeds into a digest under an estimated reading-time budget. It rotates between sources, deduplicates links and exports HTML or JSON. Python standard library only; no API key.

Includes 23 tests and a real connected run against NASA and Python Insider: four items estimated at 40 seconds within a one-minute budget.

Excerpts are publisher text, not AI summaries. The estimate covers displayed titles/excerpts, not full articles. Source terms and rate limits apply.
